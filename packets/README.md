# Returned hunt packets

Create one directory per contribution:

~~~text
packets/<topic-id>-<short-name>/
  README.md
  packet.json
  src/
  data/
  results/
  verify/
~~~

Not every directory is required, but every packet must contain enough provenance to reproduce its declared certificate. Follow the ten-field contract in [`FOR_AGENTS.md`](../FOR_AGENTS.md) and finish with one recognized disposition.
